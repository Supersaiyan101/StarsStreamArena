# 🌌 StarStream Arena

> **The first spectator-driven, on-chain battle arena on Solana.**  
> Inspired by the *Omniscient Reader's Viewpoint* (ORV) Star Stream, players build custom loadouts, race through mirrored parallel scenarios, sabotage opponents in real-time, and earn live micro-SOL tips from spectators.

## ⚡ Core Features

- **Mirrored Twin Scenarios:** Symmetrical, identical parallel arenas (The Subterranean Metro & The Flooded Metropolis) for 100% fair competitive play.
- **Dynamic 3-Card Skill Hand:** 3 active skill cards drawn every turn from your custom 5-skill deck to prevent repetitive button-mashing.
- **Anti-Pay-to-Win:** Fixed 30-point attribute allocation budget and strict Circuit stake caps (Bronze, Silver, Gold).
- **Real-Time Sabotage Engine:** Build combo energy to trigger falling debris, minion reinforcements, or thermal overloads in your opponent's arena.
- **Live Audience Tipping:** Spectators watch the split-screen broadcast and tip micro-SOL (0.001 SOL) in sub-second finality.

---

## 🛠️ Tech Stack

- **Frontend & Game Engine:** React 19, TypeScript, HTML5 Canvas, Tailwind CSS, Lucide Icons.
- **Blockchain:** Solana Devnet, `@solana/web3.js`, Phantom / Solflare Wallet.
- **VFX & Audio:** Canvas Confetti, Web Audio API sound synthesis.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Supersaiyan101/StarsStreamArena.git
cd StarsStreamArena

# Install dependencies
npm install

# Start local development server
npm run dev
```
